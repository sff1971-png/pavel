# Проект 2: IDS/IPS Suricata с кастомными правилами

##  Задача
Обнаруживать и блокировать попытки сетевой разведки и DoS-атаки.

## ⚙️ Что сделано
- Установил Suricata в режиме IPS с NFQUEUE
- Разработал кастомные правила для:
  - SYN-сканирования портов
  - ICMP-пакетов > 1000 байт (DoS)
  - HTTP-запросов с User-Agent curl
- Настроил iptables для перенаправления трафика
- Протестировал с Kali Linux (nmap, hping3)

## 💡 Ключевые выводы
- Режим IPS с NFQUEUE позволяет активно блокировать атаки
- Кастомные правила повышают точность обнаружения специфичных угроз
- Интеграция с iptables обеспечивает автоматическую блокировку

##  Сложности и решения
**Проблема:** Ложные срабатывания на легитимный трафик  
**Решение:** Настроил whitelist IP-адресов и уточнил пороги срабатывания правил
