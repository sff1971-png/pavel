# Проект 6: Защищенная сетевая инфраструктура на базе Cisco IOS

## 🎯 Задача
Развернуть и настроить защищенную сетевую инфраструктуру с динамической маршрутизацией, сегментацией и защитой от несанкционированного доступа.

## ️ Что сделано
- Настроил динамическую маршрутизацию OSPF с аутентификацией MD5
- Реализовал сегментацию сети через VLAN
- Настроил NAT/PAT для доступа в Интернет
- Реализовал ACL для разграничения трафика между сегментами
- Настроил SSHv2 с защитой от brute-force (3 попытки → блокировка 300 сек)
- Настроил пассивные интерфейсы для безопасности
- Реализовал логирование событий безопасности

##  Конфигурации
- [router-ospf.conf](./configs/router-ospf.conf) — настройка OSPF с аутентификацией
- [switch-vlan.conf](./configs/switch-vlan.conf) — конфигурация коммутатора (VLAN, trunk)
- [acl-rules.conf](./configs/acl-rules.conf) — правила доступа (ACL)
- [nat-pat.conf](./configs/nat-pat.conf) — трансляция адресов

## 💡 Ключевые выводы
- OSPF с аутентификацией MD5 предотвращает внедрение ложных маршрутов
- Сегментация через VLAN ограничивает распространение атак
- ACL критически важны для разграничения доступа между сегментами
- Защита SSH от brute-force снижает риск компрометации учетных записей
