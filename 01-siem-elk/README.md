# Проект 1: SIEM-система на базе ELK Stack

##  Задача
Организовать централизованный сбор и анализ событий безопасности с Cisco, Linux и Windows.

## ⚙️ Что сделано
- Развёрнуты Elasticsearch, Logstash, Kibana
- Настроен сбор syslog с Cisco (facility local5)
- Настроен rsyslog с Linux
- Настроен Winlogbeat + Sysmon с Windows
- Созданы раздельные индексы и дашборды

## 💡 Ключевые выводы
- Централизация логов критически важна для корреляции событий
- Раздельные индексы упрощают поиск и управление
- Sysmon даёт детализацию, недоступную стандартному Windows Event Log
