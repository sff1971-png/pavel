# Проект 3: WAF ModSecurity + Angie

## 🎯 Задача
Защитить веб-сервер от атак OWASP Top 10 (XSS, SQLi) и подозрительных User-Agent.

## ️ Что сделано
- Развернул Angie с ModSecurity
- Активировал OWASP Core Rule Set (CRS)
- Добавил кастомное правило для блокировки curl/8.14.1
- Настроил Reverse Proxy на внутренний веб-сервер
- Организовал отправку логов в SIEM (ELK Stack)

- [custom-rules.conf](./configs/custom-rules.conf) — кастомные правила
- [angie.conf](./configs/angie.conf) — конфиг веб-сервера

## 📸 Результаты
- Блокировка XSS-атак (ID 941160, 941390)
- Блокировка SQLi-попылок
- Блокировка запросов с подозрительным User-Agent

## 💡 Ключевые выводы
- OWASP CRS покрывает большинство распространённых атак
- Кастомные правила позволяют блокировать специфичные угрозы
- Интеграция с SIEM критически важна для расследования инцидентов

## 🐛 Сложности и решения
**Проблема:** Блокировка легитимных запросов с сложными формами  
**Решение:** Настроил исключения (exclusions) для определённых URL и параметров
