# Проект 4: Отказоустойчивая доменная инфраструктура Windows Server

## 🎯 Задача
Развернуть отказоустойчивую доменную среду с централизованным управлением политиками безопасности.

## ⚙️ Что сделано
- Установил три контроллера домена (DC1, DC2, DC3)
- Настроил:
  - NIC Teaming для отказоустойчивости сетевых интерфейсов
  - DHCP Failover (режим Hot Standby)
  - DFS (Distributed File System)
  - AD CS (центр сертификации)
  - IIS с HTTPS
- Автоматизировал создание OU, пользователей и групп через PowerShell
- Настроил GPO для:
  - Установки ПО
  - Настроек брандмауэра
  - Установки сертификатов
  - Баннера входа

- PowerShell критически важен для автоматизации администрирования AD

##  Сложности и решения
**Проблема:** Репликация AD между контроллерами домена  
**Решение:** Настроил Sites and Services, проверил DNS и сетевую связность
