# Проект 5: Анализ киберрисков и Security Awareness

## 🎯 Задача
Выявить угрозу, оценить риски (качественно и количественно), обосновать затраты на защиту и разработать программу обучения сотрудников.

## ⚙️ Что сделано
### Качественная оценка
- Выбрал актив: Сервер 1С
- Идентифицировал угрозу: УБИ.170 (шифрование данных)
- Построил матрицу рисков (БДУ ФСТЭК)
- Оценка: **Высокий риск**

### Количественная оценка
- AV (Asset Value) = 3 млн руб.
- SLE (Single Loss Expectancy) = 2,4 млн руб.
- ARO (Annual Rate of Occurrence) = 1 раз в год
- ALE (Annual Loss Expectancy) = 2,4 млн руб./год
- CBA (Cost-Benefit Analysis) = 1,65 млн руб. выгоды

### Security Awareness
- Разработал программу обучения сотрудников
- Определил KPI:
  - % сотрудников, прошедших обучение
  - % успешных фишинговых атак (до/после)
  - Количество инцидентов ИБ
